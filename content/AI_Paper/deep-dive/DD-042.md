# DD-042 Penguin-VL: Exploring the Efficiency Limits of VLM with LLM-based Vision Encoders

> **기관**: Tencent

## 1. 왜 이 논문이 중요한가?

기존의 시각 언어 모델(VLM)들은 모델의 크기를 무작정 키우는 방식으로 성능을 높여왔기 때문에, 스마트폰이나 로봇 같은 저전력 기기에 탑재하기에는 너무 무겁고 느렸습니다. 또한, 이미지를 이해하기 위해 반드시 CLIP이나 SigLIP처럼 별도로 거대한 데이터셋으로 사전 학습된 인코더를 사용해야 한다는 고정관념이 있었습니다. 이 논문은 거대한 시각 인코더 없이도 언어 모델(LLM) 구조 자체를 활용하여 훨씬 가볍고 효율적인 모델(Penguin-VL)을 만들 수 있음을 증명했으며, 이로써 모바일 기기에서도 강력한 멀티모달 AI를 돌릴 수 있는 길을 열었습니다.

## 2. 핵심 아이디어 쉽게 이해하기

### 일상생활 비유로 설명
기존 VLM을 '번역가'를 고용한 '소설가'라고 생각해 보세요. 소설가(LLM)는 글을 잘 쓰지만, 그림을 볼 줄 모릅니다. 그래서 그림을 해석해 주는 전문 번역가(Vision Encoder, 예: CLIP)를 별도로 고용합니다. 이 번역가는 고용 비용이 비싸고(큰 파라미터), 그림만 봅서는 텍스트를 번역해 줍니다.

반면, 이 논문에서 제안하는 Penguin-VL은 '외국어를 공부한 천재 소설가'와 같습니다. 이 소설가는 별도의 번역가 없이, 자신이 가진 언어적 지능(LLM 구조)을 활용해 그림을 직접 이해합니다. 마치 언어의 구조를 이해하듯 이미지의 패턴을 분석하기 때문에, 중간에 번역 과정이 없어 훨씬 효율적이고 빠릅니다. 즉, "눈도 언어처럼 이해하자"는 접근 방식입니다.

### 단계별 동작 원리
1.  이미지 패치화: 이미지를 작은 조각으로 나눕니다. 이것을 단어(Token) 쪼개는 것과 똑같이 취급합니다.
2.  LLM 기반 비전 인코딩: 여기서 핵심이 나옵니다. 기존의 별도 인코더 대신, 언어 모델과 유사한 구조를 가진 네트워크가 이 이미지 조각들을 읽어들입니다. 언어 모델이 문맥을 파악하듯, 이 네트워크는 이미지의 공간적, 시간적 문맥을 파악합니다.
3.  토큰 통합: 처리된 이미지 정보는 텍스트 토큰과 동일한 형식으로 변환됩니다.
4.  추론: 메인 언어 모델이 텍스트와 이미지 정보를 합쳐서 질문에 답하거나 지시를 수행합니다.

### 핵심 알고리즘
이 논문의 핵심은 사전 학습된 대규모 대조 학습(Contrastive Learning) 모델에 의존하지 않고, LLM의 가중치를 초기화나 아키텍처 설계에 활용하여 비전 인코더를 구축한다는 점입니다. 이를 통해 모델은 텍스트와 시각 정보를 더 밀접하게 통합할 수 있으며, 파라미터 수를 획기적으로 줄이면서도 성능을 유지합니다.

## 3. 실험 결과 분석

### 어떤 벤치마크에서 테스트했는가?
연구진은 이미지 이해(InfoVQA, ChartQA, DocVQA, MathVista 등)와 긴 영상 및 시간적 추론(MVBench, LongVideoBench, ActivityNet QA 등)을 포함한 다양한 벤치마크에서 모델을 테스트했습니다. 특히 정적인 이미지뿐만 아니라 시간의 흐름이 있는 비디오 이해 능력도 중점적으로 평가했습니다.

### 기존 SOTA(State-of-the-art) 대비 얼마나 좋아졌는가?
제공된 데이터에 따르면, 약 20억 개의 파라미터(2B)를 가진 Penguin-2B 모델은 경쟁 모델들인 SmolVLM2-2.2B, InternVL-3.5-2B, Qwen3VL-2B를 대부분의 항목에서 앞서거나 대등한 성능을 보였습니다.
예를 들어, InfoVQA에서 Penguin-2B는 70.8점을 기록하여 Qwen3VL-2B의 65.9점이나 InternVL-3.5-2B의 61.7점보다 현저히 높은 점수를 기록했습니다. 또한, LongVideoBench 같은 장기 영상 이해 과제에서도 54.5점으로 다른 경쟁 모델들(약 21~34점 수준)을 압도적인 격차로 이겼습니다.

### 주목할 만한 성과
가장 인상적인 점은 모델의 크기가 작음에도 불구하고, 특히 복잡한 문서 해석(ChartQA)이나 수학적 시각 추론(MathVista)에서 강력한 성과를 보여주었다는 점입니다. 이는 "거대 모델만이 좋은 성능을 낸다"는 통념을 깨고, 효율적인 아키텍처 설계가 얼마나 중요한지를 증명했습니다. 특히 영상 처리에서의 우수한 성능은 기존 이미지 위주 모델들의 약점을 극복했음을 시사합니다.

## 4. 한계점과 향후 연구 방향

### 저자가 언급한 한계
기술 리포트의 성격상 명시적인 한계점 표현은 적지만, 연구 전반에서 암시되는 한계는 초소형 모델(예: 1B 이하)으로 갈수록 발생하는 성능 저하 문제입니다. 또한, 매우 고해상도 이미지를 처리할 때 발생할 수 있는 계산 복잡도와 추론 속도 간의 트레이드오프는 여전히 최적화가 필요한 영역으로 보입니다.

### 개선 가능한 점
향후 연구에서는 이 LLM 기반 비전 인코더를 더 작은 규모의 모델(1B 또는 0.5B)로 압축하면서도 성능을 유지하는 기술이 필요할 것입니다. 또한, 현재의 성능이 주로 양적 벤치마크 점수로 나타나 있으므로, 실제 사용자 경험(대화의 자연스러움, 복잡한 지시 수행 능력 등)을 향상시키기 위한 정성적 연구와 온디바이스 디바이스에서의 실시간 추론 최적화가 이어질 것으로 기대됩니다.

## 5. 실무 적용 가능성

### 어디에 바로 적용 가능할까?
이 모델은 모바일 기기나 엣지(Edge) 디바이스에 내장되는 AI 어시스턴트로 가장 적합합니다. 예를 들어, 사용자가 스마트폰 카메라로 복잡한 차트를 찍거나 긴 영상을 촬영했을 때, 인터넷 연결 없이도 기기 자체적으로 이를 분석하고 요약해 주는 '로컬 오프라인 AI' 서비스에 즉시 활용할 수 있습니다. 또한, 서버 비용이 중요한 스타트업의 서버 사이드 모델로도 비용 효율성 때문에 매우 매력적입니다.

### 필요한 리소스
학습을 위해서는 고품질의 이미지-텍스트 쌍 데이터셋과 비디오 데이터셋이 대량으로 필요합니다. 추론 단계에서는 모델이 작기 때문에(2B~8B 파라미터), 고성능 소비자용 GPU(예: NVIDIA RTM 4090 수준)는 물론, 최신 스마트폰이나 태블릿에 들어가는 NPU(Neural Processing Unit)에서도 충분히 구동 가능할 것으로 예상됩니다. 특히 메모리 사용량이 적어 스트리밍 서비스나 실시간 로봇 제어에도 유리합니다.

## 6. 이 논문을 이해하기 위한 사전 지식

1.  VLM(Vision Language Model): 이미지와 텍스트를 동시에 이해하고 처리할 수 있는 인공지능 모델입니다. (예: GPT-4V)
2.  LLM(Large Language Model): 대량의 텍스트 데이터로 사전 학습되어 자연어 생성 및 이해에 특화된 거대 언어 모델입니다.
3.  인코더(Encoder): 입력 데이터(이미지, 텍스트 등)를 컴퓨터가 이해할 수 있는 숫자 형태의 벡터로 변환하는 신경망의 한 부분입니다.
4.  CLIP(Contrastive Language-Image Pre-training): 텍스트와 이미지를 연결하여 학습한 오픈AI의 모델로, 대부분의 VLM이 이미지 이해를 위해 기본으로 사용하는 인코더입니다.
5.  토큰(Token): 텍스트나 이미지 같은 데이터를 AI가 처리하기 위해 잘게 쪼갠 기본 단위입니다.
6.  벤치마크(Benchmark): AI 모델의 성능을 평가하기 위한 표준화된 테스트 세트입니다. (예: MMBench, VQAv2)
7.  엣지 컴퓨팅(Edge Computing): 클라우드가 아닌 데이터가 생성되는 현장(스마트폰, 사물인터넷 기기 등)에서 직접 데이터를 처리하는 컴퓨팅 방식입니다.
