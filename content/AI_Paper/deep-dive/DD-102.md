# DD-102 Crafter: A Multi-Agent Harness for Editable Scientific Figure Generation from Diverse Inputs

> **arXiv**: [2605.30611](https://arxiv.org/abs/2605.30611)
> **Upvotes**: 192 | **Comments**: 3
> **순위**: 이번 주 Top 1

---

### 1. 왜 이 논문이 중요한가?

기존의 과학 도표 생성 AI는 텍스트 입력만 가능하고 이미 한 번 그려진 그림은 수정할 수 없는 정적 이미지로만 출력되어, 실제 연구자가 필요로 하는 다양한 편집 기능을 충족하지 못했습니다. 이 논문은 실행자인 모델 자체를 바꾸는 대신, 기획, 검증, 수정을 담당하는 제어 계층인 하니스를 도입하여 텍스트뿐만 아니라 스케치나 부분 레이아웃 등 다양한 입력을 처리하고 결과물을 수정 가능한 벡터(SVG)로 변환하는 시스템을 제시합니다. 즉, 단순한 생성 모델을 넘어 실제 연구 현장에서 바로 쓸 수 있는 완성도 높은 도구를 만드는 새로운 패러다임을 제시했다는 점이 매우 중요합니다.

### 2. 핵심 아이디어 쉽게 이해하기

이 논문의 핵심은 하니스라는 개념입니다. 이를 쉽게 이해하기 위해 건설 현장을 비유로 들어보겠습니다. 기존의 AI 생성 모델은 말로만 설명을 들은 초보 목수에게 "집을 지어봐"라고 시키는 것과 같습니다. 목수는 집을 짓겠지만, 창문 위치가 틀리거나 벽이 비뚤어져도 통째로 허물고 다시 지어야 하며, 완성된 집은 나무로 지어져 나중에 벽돌로 바꿀 수 없는 구조입니다.

반면, 이 논문에서 제안하는 하니스 시스템은 건설 현장의 통합 관리 팀입니다.
첫째, 디자이너 에이전트가 고객의 요구(텍스트, 스케치 등)를 바탕으로 정밀한 도면을 계획합니다.
둘째, 실행자인 이미지 생성기가 그 도면을 보고 실제 도표를 그립니다.
셋째, 검열자가 그 도표를 검수하여 오류를 찾아냅니다.
넷째, 수정자가 피드백을 반영하여 도면을 수정하고 실행자에게 다시 작업을 시킵니다.
이 과정이 반복되며, 최종적으로는 나중에라도 부분을 수정할 수 있도록 코드 형태인 SVG로 변환해줍니다.

이러한 과정은 수식으로 표현하면 하나의 순환 구조로 정리됩니다. 현재 상태를 나타내는 명세서를 바탕으로 계획을 세우고, 실행하고, 진단하여 결과를 다시 명세서에 반영하는 루프를 돕니다. 이때 실행자는 바뀌지 않아도 주변의 지원 시스템이 훌륭하다면 최종 결과물의 품질이 보장된다는 것이 핵심 메커니즘입니다.

### 3. 실험 결과 분석

이 논문에서는 새로운 벤치마크인 크래프트벤치를 구축하여 성능을 평가했습니다. 이 데이터셋은 논문 도표, 포스터, 인포그래픽 3가지 스타일과 텍스트 생성, 마스크 채우기, 스케치 기반 생성, 핵심 요소 배치 등 총 4가지 작업 유형을 아우르는 279개의 고품질 샘플로 구성되어 있습니다. 구체적으로 살펴보면 텍스트 기반 생성이 179개로 가장 많은 비중을 차지했고, 나머지는 마스크 채우기 30개, 스케치 기반 40개, 핵심 요소 배치 30개로 구성되었습니다.

실험 결과, 제안한 방식은 기존 최첨단 모델들보다 유의미하게 높은 성능을 보였습니다. 특히 기존에 난제로 여겨졌던 복잡한 구조의 레이아웃 생성과 참조 입력을 유지하는 능력에서 큰 향상을 입증했습니다. 또한, 레스터 이미지를 수정 가능한 SVG로 변환하는 크래프트에디터 또한 기존 벡터화 방법들을 모든 평가 지표에서 압도했습니다. 구체적인 수치는 텍스트에 생략되어 있으나, 모든 구성 요소가 독립적으로 성능 향상에 기여한다는 소거 실험 결과를 통해 시스템의 효용성이 입증되었습니다.

### 4. 한계점과 향후 연구 방향

저자들은 이 하니스 접근 방식이 실행자에게 종속적이지 않다는 장점을 강조했지만, 역설적으로 기저에 있는 생성 모델 자체의 성능이 너무 낮다면 하니스가 아무리 잘 조정해도 결과물의 품질에 한계가 있을 수밖에 없다는 구조적 한계를 내포하고 있습니다. 또한, 여러 에이전트가 순차적으로 작업을 수행하고 피드백을 주고받아야 하므로, 단일 모델을 사용할 때보다 추론 시간이나 연산 비용이 상대적으로 높을 수밖에 없다는 점은 실제 서비스 환경에서 고려해야 할 요소입니다.

향후 연구로는 이 시스템이 과학 도표뿐만 아니라 웹사이트 레이아웃, 엔지니어링 CAD 도면 등 구조가 명확한 다른 산업 분야의 출력물 생성으로 확장될 수 있을 것입니다. 또한, 점점 더 강력해지는 생성 모델이 나올 때마다 하니스 코드를 수정하지 않고도 그 새로운 모델을 교체하여 성능을 끌어올릴 수 있다는 점이 지속적인 발전 가능성을 보여줍니다.

### 5. 실무 적용 가능성

이 기술은 연구소와 대학 교수진, 과학 저널리스트들에게 즉시 적용 가능합니다. 논문 작성 시 가장 시간이 오래 걸리는 도표 제작 과정을 자동화하고, 심사자의 요청에 따라 라벨을 바꾸거나 색상을 조정하는 등의 수정 작업을 SVG 코드 레벨에서 즉시 처리할 수 있게 해줍니다. 특히 기존에 인포그래픽 제작 Agency에 맡겨야 했던 고비용의 시각화 작업을 내부적으로 빠르게 처리하는 데 활용할 수 있습니다.

다만, 실제 적용을 위해서는 고성능의 GPU가 장착된 서버 환경이 필수적입니다. 텍스트를 이미지로 생성하는 확산 모델과 이미지를 이해하고 검증하는 비전 언어 모델, 그리고 이를 제어하는 여러 에이전트가 동시에 돌아가야 하므로 상당한 컴퓨팅 리소스와 메모리가 필요합니다. 또한, 고품질의 SVG를 생성하기 위해서는 프로그래밍 언어를 생성하는 모델에 대한 추가적인 튜닝과 검증 과정도 필요할 것입니다.

### 6. 이 논문을 이해하기 위한 사전 지식

- 멀티 에이전트 시스템: 여러 개의 인공지능 에이전트가 각자의 역할을 나누어 협력하며 문제를 해결하는 시스템입니다.
- 텍스트 투 이미지: 텍스트 설명을 입력으로 받아 그에 맞는 이미지를 생성하는 인공지능 기술입니다.
- 래스터 vs 벡터: 래스터는 픽셀로 이루어진 점 그림이라 확대하면 깨지지만, 벡터(SVG)는 수식과 좌표로 이루어져 확대해도 깨지지 않고 수정이 가능합니다.
- 비전 언어 모델: 이미지와 텍스트를 동시에 이해하고, 이미지를 보고 질문에 답하거나 설명할 수 있는 모델입니다.
- 확산 모델: 이미지 생성에 주로 사용되는 생성 모델의 일종으로, 점진적으로 노이즈를 제거하며 이미지를 만들어냅니다.
- 프롬프트 엔지니어링: AI 모델이 원하는 결과를 내도록 입력 텍스트나 조건을 최적화하는 기술입니다.
- 에이전트 워크플로우: 에이전트가 사용자의 목표를 달성하기 위해 계획을 세우고, 도구를 사용하며, 결과를 검토하는 일련의 과정입니다.
