## 1. IAM 권한 방향 혼동

> [!danger] 가장 많이 틀리는 패턴

### Q2 (#105) — EventBridge → Lambda 호출 권한

> [!example] 핵심 구분
> - "누가 Lambda를 **호출**하는가" → **리소스 기반 정책(resource-based policy)**
> - "Lambda가 **무엇을 하는가**" → **실행 역할(execution role)**

- 정답: D (리소스 기반 정책으로 EventBridge에 Lambda invoke 허용)
- 내 답: B (실행 역할에 EventBridge 권한 추가 → 방향 반대)

```
EventBridge ──호출──▶ Lambda
                      ↑
             리소스 기반 정책 (Lambda에서 허용)
```

## 2. 스토리지 선택 오류

> [!warning] 4문제 연속 오답 — 집중 암기 필요

### Q7 (#54) — Windows 파일 공유, 고가용성

- 정답: C (**Amazon FSx for Windows File Server**)
- 내 답: D (아마 EFS)

| 서비스 | 프로토콜 | OS |
|--------|----------|-----|
| EFS | NFS | Linux 전용 |
| FSx for Windows | SMB | Windows |
| FSx for Lustre | Lustre | HPC/Linux |

> [!danger] EFS = Linux 전용, Windows = 반드시 FSx for Windows

---

### Q10 (#324) — iSCSI + 수백 TB + 즉시 액세스 유지

- 정답: D (**Storage Gateway — Stored Volume**)
- 내 답: B (Cached Volume)

| 타입 | 데이터 위치 | 로컬 데이터 |
|------|------------|------------|
| **Stored Volume** | 전체 로컬 보관, S3에 백업 | 모든 데이터 즉시 접근 ✅ |
| **Cached Volume** | 전체 S3 저장, 자주 쓰는 것만 캐시 | 캐시 없는 데이터 지연 ❌ |

> [!tip] "모든 파일에 즉시 액세스" = **Stored Volume**

---

### Q21 (#632) — 다중 AZ EC2 여러 인스턴스 동시 접근 + 자동 확장

- 정답: C (**Amazon EFS**)
- 내 답: D (EBS)

> [!danger] EBS = 단일 AZ, 단일 인스턴스 연결 (Multi-Attach 예외 있으나 제한 많음)
> 여러 AZ + 여러 EC2 동시 마운트 = **EFS**

---

### Q36 (#293) — 로컬 액세스 유지 + AWS 자동 백업

- 정답: D (**Storage Gateway**)
- 내 답: C (DataSync)

| 서비스 | 용도 | 로컬 액세스 |
|--------|------|------------|
| **DataSync** | 일회성/주기적 마이그레이션 | ❌ |
| **Storage Gateway** | 로컬 유지하며 AWS 연동 | ✅ |

## 4. 서버리스 DB 연결

### Q11 (#354) — Lambda 폭발적 연결 → RDS 타임아웃

- 정답: D (**RDS Proxy**)
- 내 답: B (아마 Aurora Serverless)

> [!note] Lambda → RDS 연결 문제
> Lambda는 요청마다 새 연결 생성 → DB 연결 한도 초과 → 타임아웃
> 해결: **RDS Proxy** (연결 풀링, 엔드포인트만 변경하면 됨)

```
Lambda ──▶ RDS Proxy ──▶ RDS/Aurora
           (연결 풀링)
```

## 9. 핵심 암기표

|------|------------|

## 🎯 우선 암기 Top 5 (2026-03-26)

1. **Storage Gateway 타입** — Stored(전체 로컬) vs Cached(전체 S3, 캐시만 로컬)
2. **IAM 권한 방향** — 호출하는 쪽이 리소스 기반 정책 / Lambda가 쓰는 건 실행 역할
3. **FSx for Windows** — SMB 프로토콜, Windows 전용 (EFS는 Linux/NFS)
4. **RDS Proxy** — Lambda 연결 폭발 해결책
5. **교차 계정** — 항상 IAM Role + ExternalId (액세스 키 절대 금지)
