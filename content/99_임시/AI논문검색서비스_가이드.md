## 1. AI 기반 논문 검색 엔진

> [!note] 핵심 개념
> AI가 논문의 의미를 이해하고, 관련 연구를 자동으로 추천하는 차세대 검색 엔진

### 💡 Semantic Scholar

**🤔 질문**: "가장 강력한 무료 논문 검색 도구는?"

#### 📋 구체적인 특징

> [!example] 실제 성능
> 1. **규모**: 2024년 기준 18억 건 API 요청 처리
> 2. **범위**: 전 분야 학술 논문 의미 기반 검색
> 3. **기능**: AI 자동 요약, 인용 분석, 영향력 측정
> 4. **비용**: 완전 무료

**🔗 링크**: https://www.semanticscholar.org/

#### 💻 주요 기능

```yaml
# 📊 Semantic Scholar 핵심 기능
기능:
  - 의미 기반 검색: 키워드가 아닌 맥락 이해
  - 인용 그래프: 논문 간 관계 시각화
  - AI 요약: 주요 주장과 발견 자동 추출
  - 영향력 측정: 실제 학계 영향도 분석
  - API 제공: 자동화 도구 개발 가능
```

---

### 💡 Elicit - AI 연구 어시스턴트

> [!tip] 활용 팁
> 자연어로 질문하면 AI가 관련 논문을 찾아서 표로 정리해줌

#### 📊 핵심 스펙

| 항목 | 수치 |
|------|------|
| 논문 데이터베이스 | 1억 3,800만 개 |
| 임상시험 | 54만 개 |
| 포함 저장소 | arXiv, bioRxiv, Semantic Scholar |

**🔗 링크**: https://elicit.com/

#### 📋 실제 사용 예시

> [!example] 질문 형식
> - "Transformer 아키텍처의 한계는 무엇인가?"
> - "RAG 시스템의 최신 연구 동향은?"
> - "SHAP 값의 실전 적용 사례는?"

**결과**: AI가 관련 논문 5-10개를 찾아서 각 논문의 답변을 표로 정리

---

### 💡 SciSpace - 올인원 연구 플랫폼

> [!note] 특화 기능
> PDF 업로드하면 AI가 논문 내용을 실시간으로 설명

#### 📊 통합 도구

```yaml
# 📊 SciSpace 제공 서비스
통합_도구:
  - 논문 검색: 2억 8,000만 개 논문
  - 연구 도구: 150개 이상 통합
  - PDF 리더: AI 기반 실시간 설명
  - 문헌 리뷰: 체계적 문헌 조사 자동화
  - 초고 작성: 논문 작성 어시스턴트
```

**🔗 링크**: https://scispace.com/

## 2. 시각화 및 논문 발견 도구

> [!note] 핵심 개념
> 논문 간 관계를 그래프로 시각화하여 연구 맥락을 한눈에 파악

### 💡 Connected Papers

**🤔 질문**: "이 논문 읽었으면 다음에 뭘 읽어야 할까?"

#### 📋 작동 방식

> [!example] 사용 흐름
> 1. **입력**: 관심 있는 논문 1개 URL 입력
> 2. **처리**: Semantic Scholar 데이터 분석
> 3. **출력**: 관련 논문 그래프 시각화
> 4. **결과**: 클릭 한 번으로 다음 논문 탐색

#### 💻 시각화 특징

```yaml
# 📊 그래프 표현 방식
시각화:
  - 노드: 각 논문
  - 거리: 유사도 (가까울수록 관련성 높음)
  - 크기: 인용 수
  - 색상: 발표 연도
  - 연결선: 인용 관계
```

**특징**: 회원가입 불필요, 무료, 가장 빠름

**🔗 링크**: https://www.connectedpapers.com/

---

### 💡 ResearchRabbit - 2025년 대폭 업데이트

> [!tip] 2025년 신기능
> 더 깔끔한 UI, 반복 탐색 강화, 프리미엄 티어 추가

#### 📋 핵심 기능

**"논문 토끼굴 (Rabbit Hole)"**
- 한 논문에서 시작해서 계속 파고들기
- 인용 체인을 따라 자동 탐색
- 관련 저자 자동 발견

**알림 시스템**
- 관심 주제에 새 논문 나오면 이메일 알림
- 특정 저자의 신규 출판물 추적
- 컬렉션 공유 기능 (팀 작업)

#### 💻 2025년 업데이트 내역

> [!example] 주요 변경사항
> - **무료 티어**: 입력 논문 <50개, 저자 <5명, 프로젝트 1개
> - **RR+ 프리미엄**: 제한 없음
> - **Litmaps 파트너십**: 고급 시각화 기능 통합
> - **UI 개선**: 방해 요소 제거, 직관적 흐름

**🔗 링크**: https://www.researchrabbit.ai/

---

### 💡 Litmaps - 고급 시각화 전문

> [!note] 특화 기능
> 가장 정교한 인용 네트워크 시각화 및 필터링

#### 📊 비교표

| 도구 | 강점 | 약점 | 추천 대상 |
|------|------|------|----------|
| Connected Papers | 빠르고 쉬움 | 단일 논문만 | 빠른 탐색 |
| ResearchRabbit | 반복 탐색 | 학습 곡선 | 깊이 있는 조사 |
| Litmaps | 고급 필터 | 복잡함 | 전문 연구자 |

## 3. 최신 논문 큐레이션

> [!note] 핵심 개념
> 매일/매주 업데이트되는 AI 최신 연구 동향 추적

### 💡 Papers with Code - AI/ML 특화

**🤔 질문**: "SOTA 성능 모델과 구현 코드를 동시에 찾으려면?"

#### 📋 제공 내용

> [!example] 구성 요소
> 1. **논문**: AI/ML 최신 연구
> 2. **코드**: 공식 GitHub 리포지토리
> 3. **벤치마크**: SOTA 순위표
> 4. **데이터셋**: 태스크별 데이터셋

#### 💻 카테고리 구조

```yaml
# 📊 Papers with Code 분류
카테고리:
  Computer Vision:
    - Object Detection
    - Image Segmentation
    - Image Classification
  Natural Language Processing:
    - Language Models
    - Question Answering
    - Machine Translation
  Audio:
    - Speech Recognition
    - Text-to-Speech
  Graphs:
    - Graph Neural Networks
  Time Series:
    - Forecasting
```

**🔗 링크**: https://paperswithcode.com/

**특징**:
- 매일 업데이트
- 커뮤니티 투표 기반
- 댓글로 토론 가능
- 구현 코드 링크

**🔗 링크**: https://huggingface.co/papers/trending

### 💡 arXiv - 원조 프리프린트

> [!warning] 주의사항
> 심사 전 논문이므로 품질 검증 필요

#### 📋 주요 섹션

**AI 관련 카테고리**:
- **cs.AI**: Artificial Intelligence
- **cs.LG**: Machine Learning
- **cs.CL**: Computation and Language (NLP)
- **cs.CV**: Computer Vision
- **cs.SE**: Software Engineering
- **cs.DC**: Distributed Computing

#### 💻 구독 방법

```yaml
# 📊 arXiv RSS 구독
URL_형식: "https://arxiv.org/rss/cs.AI"

활용:
  - Feedly 등 RSS 리더 추가
  - 매일 아침 새 논문 체크
  - 관심 키워드 필터링
```

**🔗 링크**: https://arxiv.org/list/cs.AI/recent

## 4. 목적별 추천 조합

> [!tip] 실전 활용 전략
> 여러 도구를 조합하면 시너지 효과

### 💡 시나리오별 최적 조합

#### 📋 시나리오 1: 빠르게 관련 논문 찾기 (3분)

```
1. Connected Papers에 논문 URL 입력
2. 그래프에서 관련 논문 5-10개 선택
3. Semantic Scholar로 요약 확인
```

**소요 시간**: 3분
**결과**: 핵심 관련 논문 5-10개

---

#### 📋 시나리오 2: 깊이 있는 문헌 조사 (1-2시간)

```
1. ResearchRabbit에 핵심 논문 3-5개 추가
2. "Similar Papers" 기능으로 확장
3. 컬렉션 생성 (20-30개)
4. Semantic Scholar로 각 논문 요약 읽기
5. Elicit으로 특정 질문에 대한 답변 추출
```

**소요 시간**: 1-2시간
**결과**: 포괄적 문헌 리뷰

---

#### 📋 시나리오 3: AI 논문 + 코드 구현 (30분)

```
1. Papers with Code에서 태스크 검색
2. SOTA 모델 확인
3. GitHub 리포지토리 클론
4. 논문 읽으면서 코드 분석
```

**소요 시간**: 30분
**결과**: 이론 + 실전 구현

---

#### 📋 시나리오 4: 논문 내용이 어려울 때 (15분)

```
1. SciSpace 또는 Elicit에 PDF 업로드
2. "Explain this section" 질문
3. AI가 쉬운 말로 설명
4. 이해 안 되는 부분 계속 질문
```

**소요 시간**: 15분
**결과**: 논문 핵심 이해

---

#### 📋 시나리오 5: 매일 최신 동향 체크 (10분/일)

```
아침 루틴:
1. Hugging Face Papers 트렌딩 확인 (3분)
2. arXiv cs.AI RSS 체크 (5분)
3. 흥미로운 논문은 ResearchRabbit에 저장 (2분)
```

**소요 시간**: 10분/일
**결과**: 최신 트렌드 놓치지 않음

---

### 💡 고급 활용: 자동화 파이프라인

> [!example] 논문 모니터링 자동화
> ```yaml
> # 매일 자동 실행 시스템
>
> 1단계_수집:
>   - arXiv API로 관심 키워드 논문 수집
>   - Semantic Scholar API로 메타데이터 수집
>
> 2단계_필터링:
>   - 인용 수 > 5
>   - 저자 H-index > 20
>   - 특정 학회/저널
>
> 3단계_알림:
>   - 슬랙/이메일로 요약 전송
>   - Notion 데이터베이스에 자동 저장
>   - ResearchRabbit 컬렉션 업데이트
> ```
