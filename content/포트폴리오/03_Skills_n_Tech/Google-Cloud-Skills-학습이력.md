## 6. 실전 프로젝트와의 연결

> [!example] 학습 → 실전 적용 사례
> 이 랩 실습들은 아래 실제 프로젝트에서 활용한 GCP 서비스의 기초가 됨.

| 학습 영역 | 실전 적용 |
|----------|----------|
| Cloud Architecture | Cloud Run으로 포트폴리오 Status API 배포 |
| Data Engineering | BigQuery로 서비스 레이턴시 로깅 및 분석 |
| Kubernetes | CKA 실습 환경 구축 (Rocky Linux, Tailscale 네트워크) |
| Infrastructure as Code | Terraform으로 Cloud Run 인프라 관리 |
