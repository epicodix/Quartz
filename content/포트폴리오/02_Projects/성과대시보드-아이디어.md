# 성과 대시보드 아이디어

## 원래 구현했던 것

3D Plotly 차트로 프로젝트별 임팩트 시각화

```javascript
const projectData = [
    { project: 'Facebook Ads', cost: 100, performance: 135, time: 6 },
    { project: 'GCP Migration', cost: 40, performance: 99.9, time: 3 },
    { project: 'Kubernetes', cost: 20, performance: 120, time: 4 },
    { project: 'MLX Tuning', cost: 10, performance: 85, time: 2 },
    { project: 'Alimtalk', cost: 30, performance: 70, time: 2 },
    { project: 'XGBoost', cost: 15, performance: 85, time: 1 }
];
```

### 축 구성
- X축: 비용 절감률 (%)
- Y축: 성과 지표
- Z축: 개발 기간 (월)

## 문제점
- 하드코딩된 더미 데이터
- 실제 측정 가능한 지표가 아님
- 의미 있는 수치인지 애매함

## 개선 아이디어

### 1. 실제 측정 가능한 지표로 변경
- GitHub 커밋 수
- 배포 횟수
- 코드 라인 수
- 실제 비용 절감액

### 2. API 연동
- GitHub API로 실제 활동 데이터 가져오기
- 프로젝트별 실제 메트릭 수집

### 3. 미니 대시보드 형태
- 숫자 카드 형태로 간결하게
- 트렌드 스파크라인
