## 1. Tailscale 네트워크를 신뢰할 수 있는 네트워크로 변경

> [!tip] 가장 먼저 해볼 방법
> 이 설정만으로 대부분의 연결 문제가 해결됩니다.

### 📋 따라하기

1. 키보드에서 `Windows 키 + I` 를 눌러 **설정** 열기

2. **네트워크 및 인터넷** 클릭

3. **이더넷** 또는 **Wi-Fi** 클릭 (현재 연결된 것)

4. 화면을 아래로 스크롤하여 **Tailscale** 찾기

5. **네트워크 프로필 유형**을 **개인**으로 변경
   - 개인 = 신뢰할 수 있는 네트워크
   - 공용 = 신뢰할 수 없는 네트워크 (방화벽이 더 엄격함)

> [!warning] 주의
> "Tailscale" 어댑터가 안 보이면 Tailscale이 연결되어 있는지 확인하세요.
> 화면 오른쪽 아래 시스템 트레이에서 Tailscale 아이콘이 켜져 있어야 합니다.

## 2. 방화벽에서 Tailscale 앱 허용

### 📋 따라하기

1. 화면 왼쪽 아래 **검색창**에 `방화벽` 입력

2. **Windows Defender 방화벽** 클릭

3. 왼쪽 메뉴에서 **Windows Defender 방화벽을 통해 앱 또는 기능 허용** 클릭

4. 오른쪽 위 **설정 변경** 버튼 클릭 (관리자 권한 필요)

5. 목록에서 **Tailscale** 찾기

6. **개인** 체크박스와 **공용** 체크박스 **둘 다 체크**

7. **확인** 버튼 클릭

> [!example] 화면 예시
> ```
> ┌─────────────────────────────────────────────┐
> │ 허용되는 앱                                  │
> ├─────────────────────────────────────────────┤
> │ 앱 이름              │ 개인  │ 공용         │
> ├─────────────────────────────────────────────┤
> │ Tailscale            │  ☑   │  ☑          │
> │ tailscaled           │  ☑   │  ☑          │
> └─────────────────────────────────────────────┘
> ```

## 3. 원격 데스크톱(RDP) 허용

> [!info] 언제 필요한가요?
> Mac에서 Windows 화면을 원격으로 보고 조작하고 싶을 때 필요합니다.

### 📋 따라하기

**Step 1: 원격 데스크톱 기능 켜기**

1. `Windows 키 + I` 로 **설정** 열기

2. **시스템** 클릭

3. 왼쪽 메뉴에서 **원격 데스크톱** 클릭

4. **원격 데스크톱 사용** 스위치를 **켬**으로 변경

5. 확인 팝업이 뜨면 **확인** 클릭

**Step 2: 방화벽에서 원격 데스크톱 허용**

1. 검색창에 `방화벽` 입력 → **Windows Defender 방화벽** 클릭

2. **Windows Defender 방화벽을 통해 앱 또는 기능 허용** 클릭

3. **설정 변경** 클릭

4. 목록에서 **원격 데스크톱** 찾기

5. **개인**과 **공용** 둘 다 체크

6. **확인**

> [!tip] Mac에서 접속하는 방법
> 1. Mac에서 **Microsoft Remote Desktop** 앱 설치 (App Store에서 무료)
> 2. 앱 실행 후 **Add PC** 클릭
> 3. PC name에 **상대방의 Tailscale IP 주소** 입력 (예: 100.xxx.xxx.xxx)
> 4. Connect 클릭 → Windows 계정으로 로그인

## 4. 파일 공유 허용

> [!info] 언제 필요한가요?
> Windows 폴더를 Mac에서 접근하고 싶을 때 필요합니다.

### 📋 따라하기

**Step 1: 파일 공유 켜기**

1. `Windows 키 + I` 로 **설정** 열기

2. **네트워크 및 인터넷** 클릭

3. **고급 네트워크 설정** 클릭

4. **고급 공유 설정** 클릭

5. **개인 네트워크** 섹션 펼치기

6. 다음 항목들을 **켬**으로 설정:
   - 네트워크 검색
   - 파일 및 프린터 공유

**Step 2: 공유할 폴더 설정**

1. 공유하고 싶은 폴더를 **우클릭**

2. **속성** 클릭

3. **공유** 탭 클릭

4. **공유** 버튼 클릭

5. 드롭다운에서 **Everyone** 선택 후 **추가**

6. 권한 수준 설정 (읽기 또는 읽기/쓰기)

7. **공유** 클릭

> [!tip] Mac에서 접속하는 방법
> 1. Finder 열기
> 2. 메뉴에서 **이동** → **서버에 연결** (또는 `Cmd + K`)
> 3. 주소 입력: `smb://100.xxx.xxx.xxx` (상대방 Tailscale IP)
> 4. 연결 클릭 → Windows 계정으로 로그인

## 🔍 연결이 안 될 때 체크리스트

| 체크 항목 | 확인 방법 |
|-----------|-----------|
| Tailscale 연결됨? | 시스템 트레이에서 Tailscale 아이콘 확인 (초록색이면 연결됨) |
| 같은 네트워크? | 둘 다 같은 Tailscale 계정/팀에 속해 있는지 확인 |
| IP 주소 확인 | Tailscale 아이콘 클릭 → 본인 IP 주소 확인 |
| Windows 버전 | Home 버전은 원격 데스크톱 **호스트 불가** (Pro 이상 필요) |

## 🚨 자주 묻는 질문

### Q: Tailscale이 앱 목록에 없어요
**A:** Tailscale을 다시 설치해보세요.
1. [tailscale.com/download](https://tailscale.com/download) 접속
2. Windows 버전 다운로드
3. 설치 후 다시 로그인

### Q: 설정 변경 버튼이 회색이에요
**A:** 관리자 권한이 필요합니다.
1. 검색창에 `방화벽` 입력
2. 우클릭 → **관리자 권한으로 실행**

### Q: 원격 데스크톱 옵션이 없어요
**A:** Windows Home 버전은 원격 데스크톱 호스트를 지원하지 않습니다.
- Windows Pro 이상 버전이 필요합니다
- 대안: Chrome Remote Desktop 사용 (무료, Home도 가능)
