네이버 검색광고 데이터 수집 시스템 마이그레이션 프로젝트

📋 프로젝트 개요

마케터 6년차 → 개발자 전환 과정에서 AI(Gemini CLI + Claude Code)를 활용해 기존 Apps Script 시스템을 GCP 클라우드로 무료 이전하는 실전 학습 프로젝트

🎯 핵심 목표

  • 비용 ZERO: 무료 티어만으로 광고대행사 팀 단위 사용 가능한 시스템
  • AI 활용 실증: 비전공자도 Gemini CLI + Claude Code로 클라우드 개발 가능함을 입증
  • 실무 문제 해결: 광고업계 실제 니즈(실시간 키워드 분석) 반영
  • 커리어 전환 포트폴리오: 마케터의 도메인 지식 + 개발 능력 조합 어필

🛠 기술 스택 & AI 도구

As-Is (현재 - 마케터도 할 수 있는 수준)

  • Backend: Google Apps Script (코드 100줄 정도)
  • Database: Google Sheets (엑셀 느낌)
  • Frontend: 정적 웹사이트 (GitHub Pages)
  • 비용: 완전 무료

To-Be (목표 - AI 도움으로 달성 가능한 수준)

  • AI 개발 도구: Gemini CLI + Claude Code (핵심!)
  • Backend: Cloud Functions (서버리스, 관리 부담 ↓)
  • Database: Cloud Firestore (NoSQL, 확장성 ↑)
  • Frontend: React (모던하지만 AI가 대부분 코딩)
  • 비용: GCP 무료 티어 (월 $0 목표)
