3. API 핸들러 패턴

실제 상황

  1. 문제: API 호출 시 CORS 에러 발생
  2. 감지: 브라우저 콘솔에 “CORS policy” 에러
  3. 조치: CORS 헤더 추가
  4. 결과: API 정상 동작

💻 완전한 핸들러 템플릿

🔍 단계별 체크포인트

  • CORS 헤더 4개 모두 설정
  • OPTIONS 메서드 처리
  • HTTP 메서드 검증
  • 요청 파싱 에러 처리
  • 응답 JSON 인코딩
  • main()에 라우팅 등록 (함수 호출)

🎯 빠른 체크리스트

새 API 엔드포인트 추가 시

  1. 구조체 정의 (internal/domain/models.go)

    • 필드 대문자 시작
    • json 태그 추가
    • 주석 작성

  2. 핸들러 작성 (main.go)

    • CORS 헤더 4개
    • OPTIONS 처리
    • HTTP 메서드 검증
    • 에러 처리
    • JSON 응답

  3. 라우팅 등록 (main())

    • mux.HandleFunc("/api/...", handler())
    • 함수 호출 () 확인

  4. 테스트

    • go build 성공
    • 서버 시작
    • curl 테스트
    • 브라우저 확인
