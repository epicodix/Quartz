📚 초급 레벨 (MSA 기초)

학습 목표

MSA의 기본 개념과 핵심 패턴 이해

  1. API Gateway - 모든 것의 시작점
  2. Database per Service - MSA의 기본 원칙
  3. Retry - 기본적인 재시도
  4. Timeout - 타임아웃 설정
  5. Circuit Breaker - 장애 전파 방지

예상 학습 시간: 1-2주

🚀 중급 레벨 (실무 적용)

학습 목표

실제 프로젝트에 적용 가능한 패턴 습득

  1. Service Discovery - 동적 서비스 탐색
  2. Event-Driven Architecture - 비동기 통신의 핵심
  3. Saga - 분산 트랜잭션 관리
  4. Service Mesh - 현대적 통신 인프라
  5. Sidecar - Service Mesh의 기반
  6. Blue-Green Deployment - 무중단 배포
  7. Canary Deployment - 점진적 배포
  8. Bulkhead - 리소스 격리
  9. Rate Limiter - 속도 제한

예상 학습 시간: 2-4주

🎯 고급 레벨 (아키텍처 설계)

학습 목표

엔터프라이즈급 MSA 설계 능력

  1. CQRS - 읽기/쓰기 최적화
  2. Event Sourcing - 이벤트 기반 상태 관리
  3. API Gateway Security - API 보안
  4. Zero Trust - 제로 트러스트 보안
  5. Service-to-Service Auth - 서비스 간 인증
  6. Ambassador - 프록시 패턴

예상 학습 시간: 3-6주

🔗 패턴 관계 맵

함께 사용되는 패턴 조합

🎪 Event-Driven 스택

Event-Driven Architecture (중심)
    ├─→ Event Sourcing (이벤트 저장)
    ├─→ CQRS (읽기/쓰기 분리)
    └─→ Saga (분산 트랜잭션)

관련 문서:

  • Event-Driven-Architecture
  • Event-Sourcing-패턴
  • CQRS-패턴
  • Saga-패턴

🛡️ 복원력 스택

Service Mesh (인프라)
    ├─→ Circuit Breaker (장애 차단)
    ├─→ Retry & Timeout (재시도/타임아웃)
    ├─→ Bulkhead (리소스 격리)
    └─→ Rate Limiter (속도 제한)

관련 문서:

  • Service-Mesh-패턴
  • 서킷브레이커-패턴
  • Retry-패턴
  • Timeout-패턴
  • Bulkhead-패턴
  • Rate-Limiter-패턴

🚀 배포 스택

Sidecar Pattern (기반)
    ├─→ Service Mesh (통신 관리)
    ├─→ Blue-Green (전환 배포)
    ├─→ Canary (점진적 배포)
    └─→ Ambassador (프록시)

관련 문서:

  • Sidecar-패턴
  • Service-Mesh-패턴
  • Blue-Green-Deployment
  • Canary-Deployment-패턴
  • Ambassador-패턴

🔒 보안 스택

Zero Trust Architecture (전략)
    ├─→ API Gateway Security (외부 보안)
    ├─→ Service-to-Service Auth (내부 인증)
    └─→ Service Mesh (mTLS 암호화)

관련 문서:

  • Zero-Trust-Architecture
  • API-Gateway-Security
  • Service-to-Service-Auth
  • Service-Mesh-패턴
